 # Dollar Free 💰

**Dollar Free** is a Ruby-based terminal application designed to help users, especially students, track their expenses and develop better spending and saving habits. Users can record and review expenses, generate daily spending reports, monitor their financial health, and visualize spending patterns through terminal-based graphs.

The application also includes optional savings goals and streak-based achievements to encourage consistent saving and responsible spending.

### Core Features

* Record and manage expenses by category and amount
* View expense history
* Generate daily spending reports
* Monitor financial health and remaining budget
* Visualize spending by category using terminal-based graphs
* Set daily savings goals
* Track savings streaks and achievements

The project is developed collaboratively using **Ruby/Rails, Git, automated testing, pair programming, and incremental development practices**.
