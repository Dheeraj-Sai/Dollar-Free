# Planning Notes

## App idea

The team is building Dollar Free, a terminal expense-tracking app aimed at
students who want a simple way to record spending and build better money
habits.

## Essential features

- Main menu
- Add expense
- View expenses
- Validation for invalid user input

## Optional features

- Daily report
- Financial health check
- Spending graph
- Savings goal
- Achievements

## How work will be done

Features should be split into small stories. One person can drive while the
other person reviews the code and talks through the design. Before merging a
feature, the team should run the tests and update the user story and backlog.

## Definition of done

A story is done when:

- The feature can be used from the terminal.
- Valid and invalid input have been tested.
- The tests pass.
- The user story and backlog have been updated.
- The change has a clear Git commit message.
